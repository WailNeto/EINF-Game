# Entwicklungsphasen

- [x] **Phase 0:** Unity 2022.3 LTS, URP, Input System, modulare Grundstruktur und macOS-ARM64-Konfiguration.
- [x] **Phase 1:** Seed-basierte Insel, Forschungsstandort/Markt/Zoobereich, First-Person-Steuerung und HUD.
- [x] **Phase 2:** Fossilarten, Fundstellen und Ausgrabungsfortschritt.
- [x] **Phase 3:** Inventar, Münzen, Markt, Werkzeuge und atomare Transaktionen.
- [x] **Phase 4:** Forschung, DNA-Fortschritt und Freischaltungen.
- [x] **Phase 5:** Vogel-Fangmechanik, DNA-Verarbeitung, Eier und Dinosaurier-Lebensphasen.
- [x] **Phase 6:** Gehege, Zoo-Zuweisung, Besucher-Simulation und Einnahmen.
- [x] **Phase 7:** Versioniertes SQLite-Repository unter `Application.persistentDataPath`, Save-/Load-Menü und Snapshot-Roundtrip-Tests.
- [ ] **Phase 7 Build-Verifikation:** macOS-ARM64-IL2CPP-Build erstellen und SQLite im eigenständigen App-Build prüfen.
- [ ] **Phase 8:** Performance- und Fehlerprüfung, macOS-App-Build, Signierungshinweise und abschließender Spieltest.

In jeder Phase wird nur die zugehörige Funktionalität umgesetzt und getestet. Die nächste Phase beginnt erst nach deiner Freigabe.
